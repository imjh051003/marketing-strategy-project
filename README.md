## 2. Problem Definition

본 프로젝트에서는 다음 질문에 답하고자 했습니다.

1. 현재 브랜드가 직면하고 있는 핵심 마케팅 문제는 무엇인가?
2. 타깃 고객은 누구이며, 어떤 니즈와 행동 특성을 가지고 있는가?
3. 경쟁 브랜드와 비교했을 때 차별화할 수 있는 요소는 무엇인가?
4. 분석 결과를 실제 마케팅 전략으로 어떻게 연결할 수 있는가?
